# aerovision
The project was built to explore how modern aerospace systems visualize and process critical flight and propulsion data in real time. It combines engineering-focused UI design with telemetry visualization concepts used in aviation, defense, and aerospace monitoring environments.
# AeroVision NX

A futuristic aerospace telemetry and propulsion monitoring dashboard inspired by modern aircraft health monitoring systems and aerospace control software.

## Features

- Aircraft engine telemetry visualization
- Structural health monitoring
- FADEC status system
- Tactical radar UI
- Thermal mapping system
- Predictive maintenance analysis
- Real-time telemetry updates
- Interactive aerospace dashboard UI

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js

## Project Highlights

AeroVision NX simulates aerospace-grade monitoring software with engineering-focused telemetry systems including:

- Turbine RPM monitoring
- Exhaust Gas Temperature (EGT)
- Compressor Pressure Ratio (CPR)
- Hydraulic pressure systems
- Engine health analytics
- AI-inspired maintenance diagnostics

## Inspiration

Inspired by:
- Aerospace propulsion monitoring systems

- Industrial SCADA interfaces
- Aerospace telemetry visualization software
